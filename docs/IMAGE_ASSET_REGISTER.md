## Format note

The brief suggested WebP filenames. These are vector SVG illustrations (about 1-1.5 KB each, resolution-independent), so raster conversion would increase size and lose sharpness. Real product photographs, when ARSCON supplies them with permission, should be added as optimized WebP/AVIF with width/height attributes and recorded in this table.
